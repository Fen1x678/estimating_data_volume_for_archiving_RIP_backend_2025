Репозиторий содержит бэкенд часть лабораторных работ по курсу РИП за 2025 год.

- **ssr** - Лабораторная 1: Дизайн и верстка (Django SSR)
- **orm** - Лабораторная 2: База данных и ORM
- **rest-api** - Лабораторная 3: REST API
- **auth** - Лабораторная 4: Аутентификация и сессии

- Python/Django

- Redis

- Docker

## Предметная область:
Система оценки объёма данных веб-проекта перед архивированием с учётом алгоритмов сжатия.
Анализ и сравнение методов сжатия данных: LZW, Алгоритм Хаффмана, RLE, LZMA, JPEG, MP3.
